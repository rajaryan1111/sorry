# For Tushi — Just One Thing

A restrained cinematic 3D apology experience built with React, TypeScript, Vite, React Three Fiber, Drei, Framer Motion, Lenis, and procedural Three.js objects.

The site is intentionally friendship-focused: it apologizes, respects space, and avoids photos, fake memories, romantic imagery, or pressure to respond.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run lint
npm run build
```

## Editable copy

Most wording lives in `src/data/apologyContent.ts` so it can be adjusted without digging through components.
